# QQ群成员导出工具

> 一键导出群成员「群昵称 ↔ QQ昵称(原名)」对照表,解决群里收集信息时"只见网名、不知真人"的痛点。

## 痛点背景

班级群、社团群、工作群收集信息(问卷、表格、接龙、投票)时,统计结果里显示的往往是成员的 **QQ昵称(网名)**,而不是他们的 **群昵称**。

而群昵称通常才是真实信息——「张三-138xxxx1234」「李四-学号20240001」……

于是每次收集完,统计者都要面对一长串陌生网名,对着群成员列表逐个翻找对应,费时费力还容易对错人。

## 解决方案

本工具一键导出所选群的完整成员对照表:

| 群号 | 群名称 | QQ号 | 群昵称 | QQ昵称(原名) | 群内角色 |
|------|--------|------|--------|--------------|----------|
| 787365057 | 智能2404班级群 | 3761878354 | 智能2404李瑞19825279866 | 故事的小黄花 | 成员 |
| 787365057 | 智能2404班级群 | 3316524672 | 智能2404倪越 18914252202 | 苦力怕チタン | 管理员 |

拿到这张表后,任何收集结果里的 QQ昵称都能**秒查**到对应的群昵称/真人,统计工作一步到位。

## 功能特性

- 🖥️ **网页版界面**:暗色玻璃拟态风格,扫码登录,搜索选群,一键导出
- 🔍 **灵活选群**:输入群号或群名关键词筛选,支持多选/全选
- 📊 **Excel 导出**:自动下载,含「全部成员汇总」表 + 每个群独立工作表
- 🤖 **智能守护**:自动检测本机QQ客户端冲突、自动免扫码登录、扫码等待时二维码稳定不失效
- 🔒 **本地运行**:所有数据仅在本地处理,不经过任何云端
- ⌨️ **附带命令行版**:`导出群成员.py` 支持交互式/关键词/序号选择导出

## 快速开始

### 1. 环境要求

- Windows 10/11
- Python 3.10+
- 已部署好的 NapCatQQ(见下文)

### 2. 启动

双击 `启动网页.bat`,浏览器将自动打开 `http://127.0.0.1:8123`,按页面提示操作:

1. **登录**:首次使用扫码登录(已登录过则自动免扫码)
2. **选群**:搜索框输入群号或群名,勾选要导出的群
3. **导出**:点击「导出所选群成员」,自动下载 Excel 文件
4. **收尾**:用完点击「关闭 NapCat」

依赖自动安装:`flask` `psutil` `websockets` `openpyxl`

## NapCat 部署说明

本工具基于开源框架 [NapCatQQ](https://github.com/NapNeko/NapCatQQ),需要一个可独立运行的 NapCat 环境(内置 QQ,即 NapCat 一键包部署后得到的目录结构,包含 `bootmain\QQ.exe`、`napcat.mjs`、`config\` 等)。

- 部署完成后,将目录放在 `%USERPROFILE%\NapCatShell`(默认查找位置),
  或通过环境变量 `NAPCAT_DIR` 指定,或放在本工具同目录下的 `NapCatShell` 文件夹。
- 详细部署步骤请参考 [NapCatQQ 官方文档](https://napneko.github.io/)。

> 提示:一键包内置的 QQ 下载地址偶尔失效,若部署遇到困难,可按 NapCat 文档使用 Shell 方式部署,并确保 `bootmain` 目录下存在可运行的 QQ。

## 工作原理

```
浏览器网页(Flask 页面)
   │  REST API
本机服务(app.py, 127.0.0.1:8123)
   │  进程管理 + 状态守护
NapCat(内置QQ, 扫码登录你的账号)
   │  OneBot v11 WebSocket (127.0.0.1:3001)
QQ 服务器 → 获取群列表 / 群成员(群昵称card + QQ昵称nickname)
   │
生成 Excel(openpyxl)→ 浏览器下载
```

- 登录:QQ 官方已关闭第三方密码登录,因此**仅支持扫码登录**
- 导出数据来自 OneBot 接口的 `get_group_member_list`,其中 `card` 即群昵称、`nickname` 即 QQ 原名
